# Snake Game

Loja klasike Snake e shkruar në Python me pygame — port i plotë dhe i luajtshëm në JavaScript/Canvas: ha mollët, rritu, mos u përplas!

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

## 📁 Struktura
- `index.html — faqja showcase (Live Demo + Kodi Burim)`
- `demo/index.html — porti web i luajtshëm (Canvas)`
- `original/snake game.py — loja origjinale Python/pygame (e paprekur)`
- `original/duplicate.py — variant i dytë i kodit (i paprekur)`
- `original/*.png, *.mp3 — assetet origjinale`
- `README.md, PROVENANCE_LICENSE.txt`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python + `pip install pygame`. Ekzekuto me `python "snake game.py"` nga folderi i lojës (kërkon head.png, apple2.png, tail1.png). Kontrolli: shigjetat / WASD, P = pauzë.
